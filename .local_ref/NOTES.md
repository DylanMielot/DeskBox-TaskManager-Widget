## Build Fixes (WMC blocker resolved)
- Removed 4 XAML StaticResource converter resources (TaskManagerBoolToVisibilityConverter, TaskManagerInverseBoolToVisibilityConverter, SortColumnToVisibilityConverter, SortDescendingToGlyphConverter) — WMC0060 blocker with WinUI 2.5.1 + .NET 10 SDK; local types in UserControl.Resources not resolvable even when public
- Replaced converter bindings with computed ViewModel properties: CompactVisibility, ExpandedVisibility, CpuSortGlyph/MemorySortGlyph/DiskSortGlyph/NetworkSortGlyph, CpuSortIndicatorVisibility/…/NetworkSortIndicatorVisibility
- Fixed `d:` namespace for `d:DesignInstance`: `http://schemas.microsoft.com/winfx/2006/xaml` → `http://schemas.microsoft.com/expression/blend/2008` (WMC0615)
- Removed manual InitializeComponent/_contentLoaded/UnloadObject from code-behind — now generated by XAML compiler (LocalAssembly set via Directory.Build.targets workaround)
